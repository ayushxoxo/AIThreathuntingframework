### Cluster Output (`data/clusters/`)
**Layout:** `data/clusters/{normal,anomaly,malicious}/host_<id>_cluster_<label>.csv`
(see `clustering.py::save_cluster_files` for normal/anomaly, `train_xgboost.py::export_malicious_logs` for malicious)
- **Purpose:** HDBSCAN clustering results per host
- **Generated by:** `run_clustering.py` → `clustering.py`
- **Used by:** `train_xgboost.py`, `prometheus_exporter_xgboost.py`
- **Types:**
  - `data/clusters/normal/host_ip-10-100-1-26_cluster_0.csv` - Normal cluster 0
  - `data/clusters/normal/host_ip-10-100-1-26_cluster_1.csv` - Normal cluster 1
  - `data/clusters/anomaly/host_ip-10-100-1-26_cluster_-1.csv` - Anomalies (cluster -1)
  - `data/clusters/malicious/malicious_logs.csv` - confirmed `evil == 1` rows, written by `train_xgboost.py`

## 🐍 PYTHON SCRIPTS

### Stage 1: Clustering

#### `preprocessing.py`
- **Purpose:** Feature cleaning, encoding, scaling, PCA/UMAP
- **Used by:** `run_clustering.py`, `experiments.py`
- **Key Classes:**
  - `LogPreprocessor` - Cleans and encodes features
  - `apply_dimensionality_reduction()` - PCA/UMAP
- **Functions:**
  - Drop constant/null/correlated columns
  - Label/frequency encoding
  - StandardScaler normalization
  - PCA (95% variance) or UMAP (10D)

#### `clustering.py`
- **Purpose:** HDBSCAN clustering engine
- **Used by:** `run_clustering.py`, `experiments.py`
- **Key Classes:**
  - `HDBSCANClusterer` - Configurable clustering
- **Functions:**
  - Dynamic min_cluster_size (1-3% of data)
  - Multi-metric support (euclidean, manhattan, cosine)
  - Outlier scores & probabilities
  - Small/unstable cluster detection
  - `save_cluster_files()` - Saves results per host

#### `run_clustering.py`
- **Purpose:** Main Stage 1 pipeline
- **Execution:** `python run_clustering.py`
- **Uses:** `preprocessing.py`, `clustering.py`, `clustering_config.json`
- **Workflow:**
  1. Load `merged_output1.csv`
  2. Detect hosts (hostName column)
  3. For each host:
     - Preprocess features
     - Apply PCA
     - Run HDBSCAN
     - Save cluster files
  4. Generate summary

#### `experiments.py`
- **Purpose:** Multi-configuration testing framework
- **Used by:** Manual testing
- **Uses:** `preprocessing.py`, `clustering.py`
- **Runs 4 configs:**
  1. PCA + Euclidean
  2. PCA + Manhattan
  3. UMAP + Euclidean
  4. Scaled only + Euclidean
- **Output:** `results/experiment_results.csv`

### Stage 2: Classification

#### `train_xgboost.py` ⭐ NEW
- **Purpose:** Train XGBoost on anomaly clusters
- **Execution:** `python train_xgboost.py`
- **Uses:** `data/clusters/anomaly/*.csv`
- **Workflow:**
  1. Load all anomaly files from all hosts
  2. Create target: `label = (sus==1 OR evil==1)`
  3. Preprocess features (numeric only)
  4. Train XGBoost (400 estimators)
  5. Evaluate: Recall, F1, ROC-AUC
  6. Save model files
- **Output:**
  - `xgboost_threat_classifier.json`
  - `xgboost_feature_names.pkl`
  - `xgboost_metadata.json`

### Monitoring & Export

#### `prometheus_exporter_xgboost.py` ⭐ ACTIVE
- **Purpose:** Export XGBoost predictions to Prometheus
- **Execution:** `python prometheus_exporter_xgboost.py`
- **Port:** 8001
- **Uses:** 
  - `xgboost_threat_classifier.json`
  - `xgboost_feature_names.pkl`
  - `data/clusters/anomaly/*.csv`
- **Workflow:**
  1. Load XGBoost model
  2. Every 15 seconds:
     - Load anomaly clusters
     - Predict probabilities
     - Calculate risk tiers
     - Update Prometheus metrics
- **Metrics Exposed:**
  ```
  xgb_anomaly_total
  xgb_predicted_malicious_total
  xgb_predicted_benign_total
  xgb_high_risk_total
  xgb_suspicious_total
  xgb_avg_probability
  ```

## 🔄 DATA FLOW

### Complete Pipeline

```
1. INPUT
   merged_output1.csv (378k logs)
   
2. STAGE 1: CLUSTERING
   run_clustering.py
   ├─ preprocessing.py (clean, encode, scale, PCA)
   ├─ clustering.py (HDBSCAN per host)
   └─ OUTPUT: data/clusters/*.csv
   
3. STAGE 2: CLASSIFICATION
   train_xgboost.py
   ├─ Load all files under data/clusters/anomaly/
   ├─ Train XGBoost (sus OR evil)
   └─ OUTPUT: xgboost_threat_classifier.json
   
4. MONITORING
   prometheus_exporter_xgboost.py
   ├─ Load model
   ├─ Predict on anomalies
   └─ Export metrics (port 8001)
   
5. VISUALIZATION
   Prometheus (port 9090)
   └─ Grafana (port 3000)
```
